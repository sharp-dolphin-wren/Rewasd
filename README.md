## 📖 About

reWASD is developed by Disc Soft Ltd (the team behind DAEMON Tools) and is designed for players who want to use a gamepad on titles that only accept keyboard and mouse, or who simply prefer a custom button layout. The app works at the driver level, so remapped inputs are seen by games as native keyboard and mouse events instead of generic controller input. Recent builds add support for the DualSense Edge and improved gyro mapping, along with a reworked profile manager that lets you bind multiple configs to a single controller.

If you came looking for a reWASD download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The installer is a standard Windows setup package, so no special configuration is needed beyond a short driver install prompt on first launch. Once installed, you can create a profile, map your buttons visually and apply it globally or per application.

**Good for:** gamepad users on keyboard and mouse games · accessibility remapping · flight and racing sim players · console style layouts on PC · macro and combo mapping · streamers using controller overlays · players with custom fight sticks

## 🔑 Features

| Feature | Description |
| --- | --- |
| 🎮 **Button remapping** | Reassign any button, trigger, bumper or paddle to a keyboard key, mouse click or another controller input. |
| 🧩 **Combo mappings** | Bind two or three inputs to a single action for layered shortcuts and quick access menus. |
| ⚡ **Macro recorder** | Record a sequence of keyboard and mouse events and replay it from a controller button. |
| 🕹️ **Multi controller support** | Works with Xbox, DualShock 3 and 4, DualSense, DualSense Edge and Switch Pro controllers. |
| 🌀 **Gyro mapping** | Map gyroscope movement to mouse or right stick input for aiming and camera control. |
| 📁 **Per app profiles** | Each game or program can trigger its own profile automatically when it becomes the active window. |
| 🗂️ **Profile library** | Save, export and import profiles so layouts can be shared between machines. |
| 🎯 **Stick response tuning** | Adjust dead zones, response curves and sensitivity per stick and per axis. |
| 🔄 **Virtual controller output** | Present remapped inputs to games as a virtual Xbox 360 pad when needed for compatibility. |

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Controller not detected | Unplug and reconnect the controller, then open the Devices tab and refresh the list. |
| Remapped buttons have no effect in game | Make sure the correct profile is applied and that the game is running in the expected input mode. |
| Driver install prompt reappears | Reboot once after the first install so the virtual controller driver finishes registering. |
| Input lag or dropped presses | Lower the polling rate in the profile settings, or close background apps that capture the controller. |
| Bluetooth controller keeps disconnecting | Use a wired connection or update the Bluetooth stack from Windows Update. |
| Profile does not switch per game | Add the game executable path manually in the profile settings and reapply. |
